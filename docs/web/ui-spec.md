# React Web 规范

## 1. 页面

阶段 3：系统总览、CPU、GPU、主板传感器、内存、存储健康 / SMART、NVMe、温度历史、风扇与电压、硬件设备列表、传感器覆盖率、采集器诊断、系统配置、登录。

阶段 4：告警中心、健康评分与分析详情。

## 2. UI 规则

- 统一设计系统；组件职责单一。
- 统一加载、空数据、错误、权限不足状态。
- 统一时间格式（展示本地时区，数据为 UTC）。
- 数值必须带单位。
- `unsupported`、`permission_denied`、`unavailable`、`standby` 必须有明确的可区分展示，并说明原因。
- **缺失数据（`null`）不得渲染为 0**，图表中显示为断点而非连线。
- 历史图表必须支持时间范围选择。
- WebSocket 断开时显示连接状态，并标记数据可能不是最新。
- 不得在前端计算健康状态或评分；只展示 API 返回的分析结果。

## 3. 数据获取

- 实时数据通过 WebSocket 增量推送；历史数据通过 REST 查询。
- 禁止定时重新加载全部历史数据。
- 长时间范围使用 API 提供的聚合数据，前端只做必要的展示级降采样。
- 图表使用 ECharts。
